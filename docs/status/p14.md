## 工程用例和自然研究

P14d-B 覆盖 `SELECTED → SelectionFrozen → READY_FOR_SEALED_CONFIRMATION`、
`NO_SELECTION` 和 `FAILED_NOT_EVALUATED`，两根合计 54 个负例和 6 个 restart 用例
（每根 27 个负例、3 个 restart 用例）。
已资格化的 Replay 用例同时复用保存的 exchange 与有效 execution receipt，不再次调用 Qlib。

P14-DQ 两根合计覆盖 54 个 P14d 负例、24 个 DQ 负例和 6 个 restart 用例
（每根分别为 27、12、3 个）。
两个自然候选均产生 ValidationReport `SUCCEEDED / REJECT`、TrialOutcome `SOFT_REJECT`；
拒绝来自批准的 `G5_OUT_OF_SAMPLE / SOFT_THRESHOLD_NOT_MET` 路径。

这里的 `SOURCE_INCOMPLETE` 表示选择输入没有 eligible candidate，统计选择未执行；
不表示已批准的上游 snapshot 数据质量核验失败。

工程接受依赖完整执行与经验证的 admissible rejection gate facts。
`QLIB_EXECUTION_FAILED`、PIT、artifact、缺失证据等失败不能使用研究阈值拒绝例外。
