3. 减少完整 Python 环境和不可变输入的重复物理复制，采用显式哈希绑定、只读复用或经验证的写时复制，保持隔离及完整性要求。

4. 先完成局部修复和有意义的针对性验证。磁盘保护生效前，不启动完整验收或大规模复制。
