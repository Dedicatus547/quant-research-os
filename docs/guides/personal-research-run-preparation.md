# 个人研究运行准备：示例与证据范围

本页提供可审阅的准备模板，配合[本地完整路径](personal-research-complete.md)使用。
截至 2026-11-04，用户尚未提供新的真实研究 brief；本模板未提交 `research_prepare`，
未请求或获得真实运行授权，也未执行市场回测、采集或真实前瞻账户。
工程接受、模型提案和正式科学状态分别记录，完整交付状态以
[唯一主 handoff](../../artifacts/personal-research-complete-20261104/engineering-01/handoff.md)为准。

## 新方向到具体方案

用户只需给出研究方向及必要约束，例如：

> 请在现有沪深300日频数据和明确的费用情景下，研究一个与已停止问题独立的新方向。
> 先检索历史、设计最少充分对照并准备，不采集、不运行真实回测。

助手先查能力、已有结果、研究记忆及授权状态，说明新问题是否与既有终止问题重叠，
再设计可执行策略、对照和预算。数据身份、表达式、策略与政策哈希由系统产生并核验，
不用用户填写。`READY_FOR_AUTHORIZATION` 只表示已准备，不授予运行权限。
没有新的独立问题时保持提案状态，不为完成交付制造真实审批。

以下两候选仅说明 v7 schema、实际排序差异和预算如何固定。过去5日收益与旧趋势研究
可能重叠，因此它们不构成建议重启趋势、资格确认、confirm2 或其他已停止的同类问题。
新 brief 到来后须先确认问题独立性，再决定保留、替换或停止该示例。

| 项目 | 升序主策略示例 | 降序对照示例 |
|---|---|---|
| 评分 | 复权收盘价的过去5个实际交易会话收益 | 相同评分 |
| 排序 | 升序；代码升序打破并列 | 降序；代码升序打破并列 |
| 成员及资格 | 当时可得的沪深300历史成员、可交易状态及有限评分 | 相同分母 |
| 组合 | Top 10，单股权重上限10%，总风险上限90%，不足额留现金 | 相同 |
| 调仓及持有 | 日频，排名缓冲0，不设置最大持有期 | 相同 |
| 时钟 | 上海时区收盘后23:59形成信号，下一实际交易日开盘执行；输入 lag 0 | 相同 |

这两行的排序方向是实际算法参数，不依靠 main/control 标签改变执行。所有计算、目标、
订单和账户来自确定性表达式及 Qlib 原生路径；模型负责提案和解释。
费用情景为初始现金100万元、买入0.05%、卖出0.15%、每笔最低5元、供应商复权价格与
数量单位、200股粗交易单位和单会话成交量10%参与上限。它不代表完整交易所结算规则，
也不另加现金红利；未知权益或公司行动边界硬拒绝。

完整、可解析但未提交的请求见

## 有限预算与停止

下面是模板上限，不是已准入额度，也不是耗时预测保证。

| 范围 | 固定边界 |
|---|---|
| 历史候选执行 | 1次尝试，2个原生账户，各55会话；0后继、0自动重试 |
| 总墙钟 | 900秒，包含作业准备、执行、监督等待与清理 |
| 完整增量 | 512 MiB，包含新增信号、原生记录、导出、失败留证及控制记录 |
| 采集 | 0次，端点清单为空；只读已冻结本地输入 |
| 其他计算和费用 | 训练0、正式 Validation 0、SDK/额外模型调用0、新付费服务0 |
| 披露与调度 | 本地离线，外发0；不定时、不常驻 |

正式请求前核对实际宿主物理卷、所有并发预留、安全收尾空间和现有全局 lease。
scope 的任务逻辑输出计量与整卷安全守卫分别记录；不把整卷增长归因单个任务。
若新适配需要额外缓存或安装副本，须计入完整增量，不能只计最终报告。

PIT缺失、未来或未知依赖在执行前拒绝；权益/因子/单位或历史修订不明时停止。
额度、到期、取消或操作者 STOP 后不再发新操作。只有 intent 或未观察到真实退出的窗口
保留 UNKNOWN 和预留，先对账，不自动重放。全部计划尝试完成即可结束，盈利不是完成
条件。失败和拒绝保留原件，不能补零或从比较分母中删除。

## 真实前瞻是独立的后续准备

可供新 brief 采用的有限观察模板为：实际获授权冻结之后20个未来实际交易会话，
最多20条计划观察和20个原生账户步骤，总墙钟1800秒、完整增量512 MiB。
这是未绑定、未授权的单独提案，不包含在上述历史范围中，也没有编造未来日期或数据哈希。

现有来源止于2025-12-29，不能支持2026-11月的新前瞻推进。若未来确需该分支，先准备
明确的新快照覆盖、缺口、acquisition 端点与调用上限、到达/来源可见时间、公司行动边界、
费用和观察截止，再提出一次独立请求。新采集仍只能由既有 acquisition 层执行。
账户从原生现金开始，连续推进必须保留完整 Qlib 状态；只记录信号、导入 Position 或
历史回放都不能冒充真实未来账户。迟到补算保留 after_the_fact，不能用于按时前瞻成交。

## 工程证据和科学结论的边界

离线合成工程已经覆盖不同策略进入实际目标/成交、主策略与对照、有限后继、原 tuple
复用及 STOP。完整与逐日重建原生账户的资金、持仓、累计费用/换手、NAV、历史报告及
订单时间已做精确比较，并保留原生状态；观察也实际接入 SignalArtifact 后推进原生一步。
这不是未来业绩或正式科学验证。逐项证据、实际退出与采用范围见
[工程证据汇总](../../artifacts/personal-research-complete-20261104/engineering-01/w7-readiness/engineering-evidence.md)。

原七组、confirm2 和换手归因按原身份引用。confirm2 的 `SUCCEEDED / NOT_SUPPORTED /
NOT_EVALUATED` 仅表示其冻结范围内未获支持，保留 STOP，不重试1/3/5日确认、不转旧额度。
S/T/B 只在原定义适用时引用；新报告同时列净收益、费用、暴露、换手和未/部分成交，
未知指标保持 null，不从收益改善推断资格或因果结论。
